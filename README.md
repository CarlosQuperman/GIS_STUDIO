# GIS STUDIO

**학생과 함께 지역 데이터를 다루며 지역의 문제를 해결해 보는 수업용 지도 도구**

CSV 파일 하나로 시작해 데이터를 걸러 내고, 지도에 올리고, 행정구역·재해·토지 정보와 겹쳐 보고, 학생이 직접 조사한 내용을 지도 위에 마크다운으로 적어 **자기만의 지도 산출물**을 만들 수 있습니다. 설치 없이 HTML 파일 하나를 브라우저로 열어 씁니다.

> 이 프로그램은 **강원특별자치도교육청 교육과학정보원 2026 교육포털 콘텐츠 개발**의 일환으로 개발되었습니다.

## 만든 목적

학생들이 어려운 GIS 프로그램을 배우느라 시간을 쓰지 않고, **우리 동네의 데이터를 직접 만져 보며 문제를 찾고 해결책을 생각하는 경험**을 하게 하려고 만들었습니다.

예를 들면 이런 수업을 할 수 있습니다.

- 버스정류장·학교·공원·CCTV 같은 공공데이터를 지도에 올려 **어디가 부족한지** 찾기
- 우리 학교 반경 500 m 안에 정류장이 몇 개 있는지 재 보기
- 침수·재해 위험 구역 안에 있는 시설이 무엇인지 확인하기
- 학생이 직접 찾은 위험 지점이나 개선 제안을 마커로 찍고, 조사 내용과 사진을 붙여 **발표용 지도** 만들기

## 주요 기능

| 탭 | 기능 |
|---|---|
| **1. CSV 전처리** | 인코딩 자동 감지, 표에서 바로 수정, 조건 필터(그룹 안·그룹끼리 *모두 만족 / 하나 이상 만족 / 개별 설정*, 계산 순서와 조건별 건수 표시), 속성 고유값 보기, 주소 → 위·경도 변환 |
| **2. 공간 지도** | 마커 지도(데이터 마커와 내 마커를 같은 방식으로 편집·분석), 마커 목록(엑셀식 필터·숨기기·삭제), 행정경계·집계, 주제도(용도지역·재해·수자원 등)와 GeoJSON 불러오기, 거리·반경 분석, 마커-주제도 판정, 범례 |
| **3. 마크다운 에디터** | 문법 설명과 미리보기를 보며 마커 메모 작성(사진 삽입 가능), 지도 마커와 주고받기 |
| **작업 저장** | 데이터·마커·메모·필터·경계·주제도·화면을 **ZIP 파일 하나**로 저장하고 다시 불러와 이어서 작업(바꾸기/합치기) |

그 밖에 보여 주기용 **간단 지도 HTML 내보내기**, 수업용 가벼운 모드(타일 요청 절반), 타일 진단(느림과 오류 구분)이 있습니다.

## 시작하기

1. 이 저장소의 `gis_studio_v8.html` 을 내려받습니다.
2. 같은 폴더에 `config.js` 를 만들고 본인의 V-World 인증키를 넣습니다. ([V-World 오픈API](https://www.vworld.kr/v4po_openapi_s001.do)에서 가입 후 발급)

   ```js
   const VWORLD_API_KEY = "여기에_본인_인증키";
   const VWORLD_DOMAIN  = "localhost";   // 키를 발급받을 때 등록한 도메인
   ```

   `config.js` 없이 열면 처음 한 번 키를 물어보고, 키가 없으면 OpenStreetMap 배경으로 열립니다.
3. `gis_studio_v8.html` 을 **Chrome / Edge / 웨일**로 엽니다. (서버가 필요하면 폴더에서 `python -m http.server 8000` 후 `http://localhost:8000/`)
4. 지도 탭 → 상태 → **GIS STUDIO 폴더 연결**에서 이 html이 있는 폴더를 고르면, 저장·열기 창이 그 폴더에서 열리고 경계·주제도 JSON이 `경계`·`주제도` 폴더에 저장됩니다.

> ⚠️ **`config.js` 는 GitHub에 올리지 마세요.** 인증키는 개인 정보입니다. `.gitignore` 에 `config.js` 를 넣어 두세요.

## 사용 환경

- 최신 Chrome · Edge · 웨일 권장 (폴더 연결·저장 위치 기능은 이 브라우저들에서만 됩니다. Firefox·Safari는 다운로드 폴더로 저장됩니다.)
- 인터넷 연결 필요 (지도 타일, V-World API, Leaflet·PapaParse 라이브러리)

## 사용한 외부 서비스와 라이브러리

이 프로그램은 아래 서비스와 라이브러리를 **이용**하며, 각 자료의 권리와 이용 조건은 원 제공자에게 있습니다. 이 저장소의 라이선스는 **GIS STUDIO의 코드에만** 적용되고 이 자료들에는 적용되지 않습니다.

| 이름 | 용도 | 조건 |
|---|---|---|
| [V-World(브이월드) 오픈API](https://www.vworld.kr) — 국토교통부 | 배경 지도, 행정경계·주제도(2D 데이터 API), 주소 변환 | 각자 발급받은 인증키로 호출하며 **V-World 이용약관**을 따릅니다. 지도 화면에 출처(국토교통부 V-World)를 표시합니다. |
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | 예비 배경 지도 | © OpenStreetMap 기여자, ODbL. [타일 이용 정책](https://operations.osmfoundation.org/policies/tiles/) 적용 |
| [Leaflet](https://leafletjs.com) | 지도 엔진 | BSD-2-Clause |
| [Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster) | 마커 묶음 | MIT |
| [PapaParse](https://www.papaparse.com) | CSV 읽기·쓰기 | MIT |

라이브러리는 CDN으로 불러오며 이 저장소에 포함하지 않았습니다.

### V-World 사용에 관한 안내

- **인증키는 반드시 본인이 직접 발급**받아 쓰세요. V-World 이용약관은 인증키를 **발급받은 회원 본인만 사용**할 수 있고 타인에게 양도·제공할 수 없다고 정하고 있습니다. 이 저장소에는 인증키가 들어 있지 않으며, 작업 ZIP에도 키를 넣지 않습니다. 수업에서는 학생·교사 각자가 자기 키를 쓰거나, V-World 운영기관에 학교 단위 이용을 문의해 확인한 방식으로 운영하세요.
- 보기용 **간단 지도 HTML**에도 인증키가 들어 있지 않습니다. 파일을 열면 **본인의 V-World 인증키를 입력하는 창**이 먼저 뜨고, 키를 넣어야 지도가 열립니다(키 없이 OpenStreetMap으로 볼 수도 있습니다). 입력한 키는 보는 사람의 브라우저에만 보관됩니다.
- V-World 약관은 오픈API로 만든 프로그램의 배포를 허용하되, 결과물과 화면에 **오픈플랫폼을 이용해 만든 것임을 표시**하도록 요구합니다. 이 프로그램은 지도 화면에 "국토교통부 V-World" 출처를 표시하며, 이 표시를 지우거나 가리지 마세요.
- 약관은 V-World가 제공하는 **데이터를 무단으로 저장하거나 타인에게 제공하는 것을 제한**합니다(다운로드 서비스에 별도 라이선스가 표시된 자료는 그 라이선스를 따름). 이 프로그램은 API 호출을 줄이려고 받은 행정경계·주제도 응답을 **사용자 본인의 브라우저 저장소와 연결한 폴더**에 보관하는 기능이 있습니다. 이 기능을 쓸지는 이용자가 약관을 확인해 판단하세요. 작업 ZIP 저장 창의 "행정경계 도형"은 기본으로 빼 두었습니다(필요할 때만 체크). 보관된 `경계`·`주제도` 폴더의 JSON은 **GitHub나 다른 곳에 올리거나 다른 사람에게 주지 마세요.**
- 지도 타일·경계·주제도 **데이터 자체**의 권리는 V-World와 원 제공 기관(국토교통부, 환경부, 산림청 등)에 있습니다. 국토교통부가 저작재산권 전부를 가진 자료는 공공누리 제1유형(출처 표시)으로 이용할 수 있다고 V-World 저작권정책에 안내되어 있으나, 자료마다 조건이 다를 수 있으니 이용 전에 [V-World 이용약관](https://www.vworld.kr/v4po_prcint_a001.do)과 [저작권정책](https://www.vworld.kr/v4po_prcint_a006.do)을 확인하세요.
- 한 키로 호출할 수 있는 양에는 한도가 있어, 여럿이 한 키를 동시에 쓰면 느려지거나 중단될 수 있습니다.
- 이 프로젝트는 V-World, 국토교통부 및 어떤 기관과도 **공식 관계가 없는 개인의 비영리 교육용 프로젝트**입니다.
